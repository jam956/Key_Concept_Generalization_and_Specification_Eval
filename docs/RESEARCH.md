# Related work and predictive value

Research checked 2026-10-15. These are related methods, not validation of this repository.

- [AnaloBench (EMNLP 2024)](https://aclanthology.org/2024.emnlp-main.725/) tests analogy identification/recall with 340 human-written analogies and expanded scenarios. It is directly relevant to relational similarity and the difficulty of recovering a useful abstraction from long contexts. It does not score this exact KCE/ODRO process or demonstrate that our scores predict Cortex behavior.
- [On the Measure of Intelligence / ARC (2019)](https://arxiv.org/abs/1911.01547) motivates measuring generalization and skill-acquisition efficiency rather than equating task performance with intelligence. ARC uses visual transformations; its score cannot be assumed to predict political article construction.
- [Observational Scaling Laws and the Predictability of Language Model Performance (NeurIPS 2024)](https://papers.neurips.cc/paper_files/paper/2024/file/1cded4f97cf5f01a284c574110b7e3b9-Paper-Conference.pdf) reports that capability measures extracted from simpler benchmarks can predict selected downstream agent performance across models. This demonstrates that predictive benchmark relationships can be established empirically, not that every abstraction benchmark has that property.
- [Why Has Predicting Downstream Capabilities of Frontier AI Models with Scale Remained Elusive? (ICML 2025)](https://proceedings.mlr.press/v267/schaeffer25b.html) studies the difficulty of downstream capability prediction. It reinforces the need to state the forecast target, model population and validation regime rather than infer predictive power from a small pilot.
- [Quantifying construct validity in large language model evaluations (2026 thesis/preprint)](https://arxiv.org/abs/2602.15532) proposes an interpretable capability model and reports improved out-of-distribution benchmark prediction compared with scaling-law alternatives. This is evidence within that study, not a settled guarantee that benchmark factors are general cognitive faculties.

The distinctive local contribution is an inspectable separation of overgeneralization, undergeneralization, generation and control leakage. We have not established novelty relative to every existing benchmark. Its immediate value is diagnostic; prospective, held-out validation is required before calling it a predictor of model cognitive ability. See [VALIDATION.md](VALIDATION.md).

GitHub packaging: [official file-size guidance](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github) documents the 100 MiB ordinary-file limit and alternatives. The full local Expressions database exceeds that limit and contains unrelated works, so this repository uses an optional work-scoped export.
